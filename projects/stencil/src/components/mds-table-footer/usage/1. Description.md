The `<mds-table-footer>` web component is a structural child of [`<mds-table>`](../../mds-table) that renders the footer row of a table - typically used for totals or summaries. Unlike the native `<tfoot>`, it is itself a row (`role="row"`, `display: table-row`): its single slot takes `mds-table-cell` children directly, one per column.

#### Semantic Behavior

- **Compound child only**: Must be placed as a direct slot child of `<mds-table>`, alongside `mds-table-header` and `mds-table-body`; it is not used standalone or nested inside another child type.
- **Structural passthrough**: It renders nothing but a single default slot - a purely structural wrapper with no rendered chrome of its own.
- **Lines up with the rows**: The footer is no selectable data row, but it keeps the columns of one: in a `selectable` table the parent sets the footer's `selectable` and the footer adds an empty first cell, where the rows have their checkbox; when the rows have `slot="action"` content on load, it adds an empty last cell, where the rows have their actions.

#### Properties & Visual Configurations

`<mds-table-footer>` has one prop, `selectable`, which `<mds-table>` sets: leave it to the parent. Its main API is its **default slot**, into which you place one `mds-table-cell` per column of your data, not counting the selection and actions columns. Visual styling (background, borders, cell padding) is inherited from the CSS custom properties defined on the parent `<mds-table>`.
